Using Google Photos?
  1. Select the photos (or open an album) in Google Photos.
  2. Tap Share → Create link and copy it.
  3. Paste it here - all shared photos load automatically.
Tip: tick Auto-update for Google Photos links so the gallery always pulls fresh image addresses from Google.
